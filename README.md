# Tarjem — مُترجم الشغل (أوفلاين)

برنامج ويندوز لترجمة المراسلات والمستندات من العربي للإنجليزي (والعكس)، بيشتغل بالكامل على الجهاز من غير إنترنت، ومعاه قاموس مصطلحات هندسية وإدارية ومحاسبية.

## التسطيب
1. نزّل `Tarjem-Setup-x.y.z.exe` من صفحة **Releases** في الريبو ده.
2. شغّله وكمّل خطوات التسطيب. (ويندوز ممكن يظهر تحذير SmartScreen لأن البرنامج مش موقّع: اضغط **More info** وبعدين **Run anyway**.)
3. افتح «Tarjem - مترجم الشغل» من سطح المكتب.

فيه كمان نسخة محمولة `Tarjem-Portable-x.y.z.zip`: فكّها في أي فولدر وشغّل `Tarjem.exe`.

المتطلبات: ويندوز 10 أو 11 (64-bit)، ومساحة حوالي 1 جيجا. البرنامج بيستخدم WebView2، وهو موجود أصلًا في ويندوز 10 المحدّث وويندوز 11.

## إزاي بيشتغل
- **الترجمة**: موديلات OPUS-MT من جامعة هلسنكي (`opus-mt-tc-big-ar-en` و `opus-mt-tc-big-en-ar`، ترخيص CC-BY-4.0)، متحوّلة لـ CTranslate2 بدقة int8 علشان تشتغل بسرعة على المعالج.
- **إلزام المصطلحات**: قبل الترجمة، البرنامج بيدوّر على مصطلحات القاموس ومصطلحاتك في النص ويحط مكانها المقابل المعتمد، علشان المصطلح يطلع ثابت في كل مرة. تقدر تقفل الخاصية دي من الشاشة.
- **مصطلحاتي**: بتتحفظ في `%APPDATA%\Tarjem\my_terms.json`.

## للمطوّر
```
pip install -r requirements.txt
# مرة واحدة (محتاجة نت + torch + transformers):
python scripts/convert_models.py
python -m app.selftest
python app/main.py
```
ملف التسطيب بيتبني أوتوماتيك على GitHub Actions (`.github/workflows/build-windows.yml`): شغّله يدوي من تبويب Actions، أو اعمل tag زي `v1.0.0`.

إضافة مجالات جديدة للقاموس: ضيف ملف في `ui/data/` بنفس شكل الملفات الموجودة، وسجّله في `ui/index.html`.
